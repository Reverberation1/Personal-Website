# Personal Website — Claude Instructions

## Project Type
Jekyll static site. Content in `pages/`, layouts in `_layouts/`, styles in `_sass/`.

## Commands
```bash
# Build
bundle exec jekyll build

# Serve locally
bundle exec jekyll serve
```

## Rules
- Keep it minimal. Don't add dependencies without a clear reason.
- `_site/` is build output — never edit directly.
- Styles live in `_sass/` only.
