# Personal Website — Constitution

## Mission

A minimal personal website at kester.world. Simple, fast, static.

## Tech Stack

| Layer | Choice | Role |
|-------|--------|------|
| Framework | Jekyll | Static site generator |
| Styles | Sass (compressed) | CSS preprocessing |
| Markdown | kramdown | Content rendering |
| Syntax highlighting | rouge | Code blocks |
| Hosting | (static host) | Served from `_site/` |

## Non-Goals

- CMS or dynamic content
- Comments or user accounts
- Analytics beyond what the host provides
- Complex JavaScript
